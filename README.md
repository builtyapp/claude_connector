# Builty Claude connector

Claude Code plugin marketplace for [Builty](https://builtydata.com): US building permit and property data.

```bash
claude plugin marketplace add builtyapp/claude_connector
```

```bash
claude plugin install builty@builty
```

| Plugin | Description |
| --- | --- |
| [builty](plugins/builty) | Permit history and permit-derived property characteristics for ~143M US buildings, via the hosted MCP server at `https://api.builty.app/mcp` |
